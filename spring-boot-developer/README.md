# Spring Boot Full-Stack Developer

An Agent Skill for creating and maintaining Spring Boot applications. Generate a Spring Boot backend with Maven or Gradle, add PostgreSQL and Docker support, and integrate Vue, React, Next.js, Angular, or vanilla JavaScript.

## What This Skill Provides

- **Project generation** of Spring Boot 4.x projects from Spring Initializr; guides target Boot 4, and changes to existing Boot 3.5.x projects use the consolidated differences in the migration guide
- **PostgreSQL and Docker support** with development and full-stack Compose configurations
- **Selectable persistence** with JPA (default), MyBatis-Plus, or no persistence framework
- **Backend guidance** for REST APIs, persistence, validation, security, configuration, testing, application architecture, and optional local BootUI diagnostics; security guidance covers both browser sessions and stateless Bearer APIs
- **Frontend integration guides** for Vue, React, Next.js, Angular, and vanilla JavaScript
- **Deployment guidance** for Docker, GraalVM Native Image, and Azure Container Apps
- **Existing-project support** for implementation, debugging, version migration, and verification
- **A hands-on workshop** that builds and verifies a Spring Boot, Vue, and PostgreSQL CRUD application

The generator creates the backend project. Frontend applications are added in a separate integration step using the matching guide.

## Quick Start

Run the environment checker and project generator from this directory. Set `--output-dir` to a workspace outside the skill directory:

```bash
node scripts/check-environment.mjs --docker
node scripts/create-project.mjs \
  --name inventory-api \
  --group-id com.example \
  --docker \
  --output-dir /absolute/path/to/workspace
```

The defaults are JPA persistence and PostgreSQL. Choose `--persistence jpa|mybatis-plus|none` and `--database postgresql|none` as needed. For example, use `--persistence none --database none` for a web-only backend or `--persistence mybatis-plus` for MyBatis-Plus with the default PostgreSQL setup. Generated Maven and Gradle projects include Spotless Java formatting, applied once after generation; Maven PostgreSQL/Testcontainers projects use Failsafe for `*IT` tests. The wrapper-based `Taskfile.yml` includes `format`, `test`, and `verify` tasks, and a Temurin `.sdkmanrc` matching the selected Java major. VS Code and Dev Container files are not generated by default; frontend scaffolding is performed separately. Use `node scripts/create-project.mjs --help` to see all options. The generator does not overwrite an existing target, install global tools, or initialize Git. Docker generation requires Maven and PostgreSQL.

## Using This Skill with AI Assistants

This directory follows the [Agent Skills specification](https://agentskills.io/specification). Add or copy the `spring-boot-developer` directory to a skills location supported by your coding assistant, then invoke it for Spring Boot work. Skill discovery paths vary by assistant; consult that assistant's documentation if the skill is not discovered automatically.

When requesting a new application, state the target workspace and required technologies. For example:

```text
Use spring-boot-developer to create an application in my workspace.
Use PostgreSQL and Docker Compose. Add a Next.js frontend and CRUD for products.
```

For an existing application, specify the requested behavior and relevant constraints. The skill will inspect the project version and conventions, then use the corresponding guides.

## Requirements

- Node.js to run the project generator and environment checker
- Java supported by the selected Spring Boot release
- Docker with Compose for container workflows
- Node.js and npm for frontend development
- Network access to Spring Initializr and dependency repositories for generation and dependency resolution

The supported version baselines and generator defaults are recorded in [`versions.json`](versions.json). Check the [version compatibility guide](references/spring-boot-migration.md) before changing those values.

## Maintaining the Generator

After changing `versions.json`, `scripts/create-project.mjs`, or the project setup assets, run the smoke test. It generates Maven, Gradle, MyBatis-Plus, no-database, and Docker projects, runs their full builds, starts the Docker project's Compose stack with Java 21 bytecode and probes its health endpoint, and checks that invalid option combinations are rejected. It needs network access and a running Docker daemon.

```bash
node scripts/smoke-test.mjs
```

Run `node scripts/sync-versions-in-docs.mjs --check` to confirm the version tables and inline frontend build versions in the guides still match `versions.json`.
