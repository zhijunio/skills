# Collected skills

This directory gathers skills from other projects for reference and individual use. Each skill's `SKILL.md` describes when to use it.

## SDD companions

- [domain-modeling](domain-modeling/SKILL.md) for clarifying shared concepts and rules during specification.
- [prototype](prototype/SKILL.md) for trying a UI flow or state model before spec approval.
- [diagnosing-bugs](diagnosing-bugs/SKILL.md) for reproducing complex defects or performance regressions during implementation.
