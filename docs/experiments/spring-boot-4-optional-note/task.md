给已有文档 PATCH /api/documents/{id} 增加可选备注 note。title 仍然必填，只修改 title 时的结果与现在一致。

备注规则：
- 请求不包含 note 时，已保存的备注保持不变。现有文档没有备注，不带 note 的读取和成功写入响应保持现在的 JSON，不要新增字段。
- note 为 JSON null 时清空备注，之后的读取和成功响应也不包含 note。
- note 为空字符串时保存空字符串，响应包含 "note":""。
- note 最长 40 个字符。40 个字符成功保存；41 个字符拒绝，文档保持拒绝前的 title 和 note。
- 缺少 title 时拒绝，文档不变。
- 拒绝时沿用应用现有的错误响应方式。

保留已有会话登录、资源归属、CSRF、偏好设置接口和现有状态码。补充验证，并使用项目 Maven Wrapper 运行检查。项目中的账号仅用于本地实验。
