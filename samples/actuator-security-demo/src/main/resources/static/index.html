业务 API 与 Actuator 使用不同的安全链、authority 和端口。存活与就绪探针可匿名访问，其余管理操作需要专用权限。

TRY IT LOCALLY

请求示例

公开探针，无需凭据curl http://localhost:9090/actuator/health/liveness
管理操作，专用账号curl -u "$MANAGEMENT_USERNAME:$MANAGEMENT_PASSWORD" http://localhost:9090/actuator/health
业务 API，业务账号curl -u "$BUSINESS_USERNAME:$BUSINESS_PASSWORD" http://localhost:8080/api/orders

演示账号密码通过环境变量注入。页面和账户仅用于本地学习，不是生产身份系统。

本示例不使用数据库。生产部署还需结合防火墙、服务网格或私有网络限制管理端口的可达范围。
