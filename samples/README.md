# Samples

Runnable sample applications for the Spring Boot skills in this repository.

| Sample | Stack | Description |
|---|---|---|
| [sb4-jpa-task](sb4-jpa-task/README.md) | Spring Boot 4, Java, Maven, PostgreSQL, Redis, JPA, OAuth2 Resource Server | Task API with JWT scopes, RFC 9457 errors, OpenAPI, Jackson rules, Redis caching, ArchUnit, and integration tests. |
| [sb4-jwt](sb4-jwt/README.md) | Spring Boot 4, Java, Maven, PostgreSQL, JdbcClient, Spring Security | Persistent local accounts and stateless RS256 JWT login without refresh tokens. |
| [sb4-mfa](sb4-mfa/README.md) | Spring Boot 4, Java, Maven, Spring Security 7, WebAuthn, Web3j | In-memory browser-session demo with TOTP, email code, wallet signature and WebAuthn/Passkey flows. Wallet mnemonic phrases are explicitly rejected. |
| [sb4-jpa-vue-product](sb4-jpa-vue-product/README.md) | Spring Boot 4, Java, Maven, PostgreSQL, JPA, Vue | Product application with a Vue frontend and Spring Boot backend. |
| [sb4-oauth2-login](sb4-oauth2-login/README.md) | Spring Boot 4, Java, Maven, Spring Security 7, PostgreSQL, OAuth2 Client, JWT, HTML/CSS/Vanilla JS | Chinese login UI with database-managed OAuth templates and clients, audit history, in-memory local accounts, and GitHub, Google, Facebook, Apple, Dex, or custom OIDC login. |

Read each sample's README for prerequisites, configuration, and run commands. These projects illustrate the skill's guidance; adapt them to the target project's requirements rather than treating them as universal templates.

See [planned Spring Security samples](ROADMAP.md) for approved examples that are not implemented yet.
