# Samples

Runnable sample applications for the Spring Boot skills in this repository.

| Sample | Stack | Description |
|---|---|---|
| [sb4-jpa-task](sb4-jpa-task/README.md) | Spring Boot 4, Java, Maven, PostgreSQL, Redis, JPA, OAuth2 Resource Server | Task API with JWT scopes, RFC 9457 errors, OpenAPI, Jackson rules, Redis caching, ArchUnit, and integration tests. |
| [sb4-jpa-vue-product](sb4-jpa-vue-product/README.md) | Spring Boot 4, Java, Maven, PostgreSQL, JPA, Vue | Product application with a Vue frontend and Spring Boot backend. |

Read each sample's README for prerequisites, configuration, and run commands. These projects illustrate the skill's guidance; adapt them to the target project's requirements rather than treating them as universal templates.
